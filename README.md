# 2-4's TOY WORLD

的を撃つシューティングギャラリーのWeb版です。もとはpygame製（`TSM_core_2.py`と`TSM_mode1〜5.py`）で、ブラウザだけで遊べるように作り直しました。

- **遊び方を選べる**: 通常（画面をタップ）／AR（スマホを向けて狙う）
- **長さを選べる**: 60秒・3ステージ／120秒・全5ステージ
- **ARは2人でも遊べる**（スマホ2台を直接つなぐ）
- **ランキングはGoogleスプレッドシートで管理**できる

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | ゲーム本体（画面・ステージ・AR・通信が1つにまとまっています。背景画像とBGMも中に入っています） |
| `Code.gs` | Google Apps Script用。ランキングの記録と、2人プレイの「待ち合わせ」を担当します |
| `README.md` | このファイル |

ゲーム画面は**GitHub Pages**、保存と待ち合わせは**Google Apps Script（GAS）**、と役割を分けています。

```
スマホ・PC ──(ゲームを開く)──▶ GitHub Pages（index.html）
     │
     ├──(ランキングの保存・取得／2人の待ち合わせ)──▶ GAS（Code.gs）──▶ スプレッドシート
     │
     └──(ARの2人プレイ中は、スマホ同士が直接つながる)── 相手のスマホ
```

## セットアップ

### 1. GASを用意する（最初の1回）

1. [script.google.com](https://script.google.com/) →「新しいプロジェクト」
2. 最初に入っているコードを全部消して、`Code.gs`の中身を貼り付けて保存
3. 上の関数選択で **`setup`** を選び、「実行」を押す
   - 権限の確認が出るので許可します。「Googleは、このアプリを確認していません」と出たら、「詳細」→「（プロジェクト名）に移動」で進みます。自分で書いたスクリプトなので問題ありません。
   - 自分のGoogleドライブに、スプレッドシート「**2-4's TOY WORLD スコア**」が自動で作られます。URLは「実行ログ」に出ます。
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「**ウェブアプリ**」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
5. 発行された、`/exec`で終わるURLをコピー

> コードを書き換えたときは、「デプロイ」→「デプロイを管理」→鉛筆アイコン→「**新しいバージョン**」で更新してください。保存しただけでは、`/exec`のURLに反映されません。

動作確認: ブラウザで`（コピーしたURL）?api=state`を開いて、`{"ranking":{}}`のような表示が出れば成功です。

### 2. `index.html`にGASのURLを入れる

`index.html`をテキストエディタで開き、先頭近くの次の行を探します。

```js
const GAS_URL = "";
```

`""`の中に、コピーした`/exec`のURLを貼り付けます。

> お試しなら、ファイルをいじらずに、アドレスの後ろに`?gas=（URL）`を付けても動きます。

### 3. GitHub Pagesで公開する

1. リポジトリの一番上に`index.html`を置く
2. リポジトリの「Settings」→「Pages」→ Source を「Deploy from a branch」、Branchを`main`／`/(root)`にして保存
3. 数分後に、`https://（ユーザー名）.github.io/（リポジトリ名）/`で開けます

> ARはカメラと傾きセンサーを使うため、`https`のページでないと動きません（GitHub Pagesはhttpsです）。

## 遊び方

スタート画面で、3つを選んで「スタート」を押します。

| 選ぶもの | 選択肢 |
|---|---|
| 長さ | **60秒・3ステージ**（5つの中からランダムに3つ）／**120秒・全5ステージ** |
| あそび方 | **通常（タップ）**／**AR（スマホを向ける）** |
| 人数（ARのみ） | **1人**／**2人（通信）** |

### 5つのステージ

| ステージ | ルール |
|---|---|
| Ham & Eggs | 出てきた的が消える前に撃つ。小さい的ほど高得点（100〜700）。だんだん出る間隔が短くなる |
| Rex & Trixie | LAVA → ERUPTION → METEOR → SHOWER の順に撃ってコンボをつなぐ。最後は5000点 |
| Green Army Men | 飛んでくるお皿を、いちばん高い所（PEAK）で撃つとボーナス。8秒ごとにタンクが飛んでくる（高得点） |
| Buzz Lightyear | エイリアン8体を倒すとロボットが出る。口が開いた瞬間を撃つと2000点。周りを回る的は300点 |
| Woody's Gallery | 100点の的32個を全部撃つと、500点の的と中央の5000点が出る。500点を2つ続けて撃つと2000点ボーナス |

### 通常モード

画面をタップ（クリック）して撃ちます。2本目の指でタップすると、赤い2つ目の照準が出ます（得点は合算）。

### ARモード

- スマホを、カメラのように構えます。カメラ映像の上に「仮想ディスプレイ」（ゲームの画面）が、空間に固定されて浮かびます。
- スマホを動かして、画面中央の照準を的に合わせ、**画面をタップして撃ちます**。
- 照準がズレてきたら、右下の「**中央に合わせる**」を押します（今向いている先がディスプレイの中心になります）。
- **ステージが切り替わるとき、ディスプレイが左右（正面から最大70度）に動きます。** 紹介画面に動く方向が出るので、体ごと向きを変えて追いかけます。ディスプレイが視界の外にあるときは、「→ 画面は右にあります」のような案内が出ます。
- iPhoneでは、最初に「動きと向きへのアクセス」の許可が出ます。
- PCでは、傾きセンサーがないためARは使えません。

### ARの2人プレイ

1. 2人とも、「あそび方: AR」「人数: 2人（通信）」を選んで「スタート」
2. 片方が「**部屋を作る**」を押すと、4けたの番号が出る
3. もう片方が、その番号を入力して「**入る**」
4. つながったら、2人とも**同じ向きに構えて**「準備OK」を押す
5. ホストが「スタート」を押す

同じ的を2人で撃ちます。相手の照準は赤で見えます。スコアは、**それぞれの名前で別々に**ランキングに載ります（結果画面には相手のスコアと合計も出ます）。終わったあとは、つないだまま次の準備に戻れます。

### 観戦（見るだけで参加する）

ARの部屋には、遊ぶ人のほかに、**見るだけの人（観戦者）が4人まで**入れます。会場の大画面に映したり、観客が自分のスマホで見たりできます。

**観戦のしかた**

1. スタート画面の **「👀 観戦する」** を押す
2. 遊んでいる人から聞いた**4けたの番号**を入れて「観戦する」を押す
3. つながると、ゲームの画面がそのまま映ります。やめるときは、右下の「観戦をやめる」を押す

**遊ぶ人の側**

- **2人プレイ**: 「部屋を作る」で出る番号が、そのまま観戦の番号です。観戦者の人数は、準備の画面に出ます。
- **ひとりのAR**: スタート画面で「AR」→「1人」を選ぶと、「観戦を受け付ける（番号を出します）」のチェックが出ます。入れてスタートを押すと、番号が出ます。「スタート」はいつでも押せます（観戦者がいなくても始められます）。

**観戦の画面で見えるもの**

- ディスプレイ全体（的、得点の表示、残り時間、ステージの案内）
- 2人プレイでは、ホストの照準（黄色）とゲストの照準（赤）、2人それぞれの得点
- ゲームが終わると、結果とランキング。「次のゲームを待っています…」と出て、遊ぶ人が再戦すると、自動で続きが見られます

**ルール**

- 観戦者は、見ることしかできません（ゲームには影響しません）。
- 途中から入ってもOKです。入った時点の場面から見られます。
- 5人目は「満員です（観戦は4人までです）」と出ます。
- 観戦できるのは、今のところ**ARの部屋だけ**です（通常モードは対象外です）。
- 観戦者に画像・BGM・カメラは要りません。PCのブラウザでも見られます。

> 観戦者が増えるほど、遊ぶ人（ホスト）のスマホの負担が増えます。熱くなる、動きが重くなる場合は、観戦者を減らしてください。


## 設定（右上の⚙）

| 設定 | 内容 |
|---|---|
| ディスプレイの外側を現実（カメラ映像）にする | オフにすると、外側は何もない暗い空間になります。カメラの許可も出ません |
| 使うカメラ | 標準は「自動（背面カメラ優先）」です。PCやUSBカメラなど、複数のカメラがあるときは、ここで選べます（一度カメラを許可したあとに、一覧が出ます） |
| ステージが変わるとき、ディスプレイが左右に動く | ARの動きのオン／オフ。2人のときは、ホストの設定が使われます |
| 背景画像・ターゲット画像・BGM | 好きな画像や音に差し替えます。ミュートもできます |

設定は、**その端末だけ**に保存されます（他の端末には共有されません）。

## ランキングと管理

ランキングは、遊び方ごとに6つに分かれています。

- 60秒・通常／120秒・通常
- 60秒・AR／120秒・AR
- 60秒・AR 2人／120秒・AR 2人

結果画面には上位8件、スタート画面の「🏆 スコアボード」には上位15件が出ます（5秒ごとに自動更新）。ランキングに載るのは、各ランキングの上位30件までです。

### スプレッドシートで管理する

スコアは、1プレイ＝1行で、スプレッドシートに記録されます。

| 日時 | モード | 名前 | スコア | 非表示 |
|---|---|---|---|---|
| 2026/10/18 14:30 | 60_normal | たろう | 1200 | |

- **行を削除する**、**名前やスコアを書き換える** → ランキングにそのまま反映されます（数秒かかります）
- **「非表示」の列に何か入れる**（例: ×） → 記録は残したまま、ランキングから隠せます
- 名前が「`=`」「`+`」「`-`」「`@`」で始まる場合は、その文字が取り除かれて記録されます（計算式として動かないようにするため）

### 記録しない名前（コマンド）

名前の入力欄に、**「`/`」または「`／`」で始まる名前**（例: `/test`）を入れると、ランキングには**記録されません**。テストプレイや、練習のときに使います。

> 「スキップ」ボタンは記録されます（名前は「ななし」になります）。

## 困ったとき

| 症状 | 確認すること |
|---|---|
| 画面の上に赤い警告が出る | `index.html`の`GAS_URL`にURLが入っていません |
| 「ランキングに接続できません」 | GASを「新しいバージョン」でデプロイしたか／アクセスできるユーザーが「全員」か／URLが`/exec`で終わっているか |
| スコアボードが古いまま | 更新は5秒ごとです。スプレッドシートを直した場合も、数秒かかります |
| ARが使えない | PCでは使えません。スマホで、`https`のページを開いているか確認。iPhoneは許可の画面で「許可」を選びます |
| カメラが映らない | ブラウザのカメラ許可を確認。許可しなくても、「現実を使わない」設定で遊べます |
| PCだと手前向き（フロント）のカメラになる | PCのカメラは、通常、手前向きです。⚙設定の「使うカメラ」から、別のカメラ（USBカメラなど）を選べます。選んだカメラが使えないときは、自動で選び直します |
| 照準が少しずつズレる | 「中央に合わせる」を押します |
| 2人プレイでつながらない | 会場のWi-Fiが、端末同士の通信を止めている可能性があります。別のWi-Fiや、スマホのテザリングで試してください |
| 観戦できない／「部屋が見つかりませんでした」 | 番号が合っているか、遊ぶ人が先に部屋を作った（またはひとりのARで「観戦を受け付ける」を入れてスタート画面から進めた）か確認してください。観戦もWi-Fiの制限の影響を受けます。5人目以降は「満員」になります |
| 「確認されていません」が出る（GAS） | 自分で書いたスクリプトなので、「詳細」→「移動」で進んで大丈夫です |

## 仕組み（技術メモ）

- **ステージの長さ**: 紹介1.5秒＋プレイ。60秒は1ステージ18.5秒×3、120秒は1ステージ22.5秒×5
- **ARの向き計算**: スマホの傾きセンサー（`deviceorientation`）から、背面カメラが向いている方向（左右・上下）と、画面の傾きを求めます。仮想ディスプレイは横50度ぶんの広さで、画面の長い辺は約60度ぶんを映します
- **2人プレイの通信**: WebRTCのデータ通信を使います。ホストが的の動きとスコアを計算して、約15回／秒でゲストへ送ります。ゲストは照準と発射だけをホストへ送ります。2台をつなぐための最初のやり取りだけ、GAS経由です（30分で消えます）
- **観戦の通信**: 観戦者は、ホストと1対1でそれぞれつながります（観戦者が増えるほど、ホストの送る量が増えます）。ホストは2秒ごとに、GASで観戦の申し込みを確認して返事をします。4人を超えた申し込みには「満員」と返します。観戦者からホストへ送るものは、ありません
- **GASのデータ**: ランキングはスプレッドシート、待ち合わせ情報はキャッシュに置きます。ランキングは5秒だけ使い回して、読み込みを軽くしています
- **外部のもの**: 文字（Google Fonts）と、通信を助けるSTUNサーバー（`stun.l.google.com`）を使っています

## 注意

- `/exec`のURLを知っている人は、ランキングに書き込めます。入っているのは名前とスコアだけですが、展示の関係者以外にはあまり広めないでください
- 名前に個人情報を入れないよう、遊ぶ人に伝えてください
- ステージ名やキャラクター名は、トイ・ストーリー由来です。学校行事など、非営利の範囲での利用にとどめ、公開の範囲に気をつけてください
- AR・2人プレイは、PC上の模擬環境で動作を確認しています。実機での最終確認は、本番前にお願いします
